v1.1.0

This version introduces MixinExtras (bundled with Fabric Loader 0.19.3, no extra dependency required), and refactors all the standard Mixin injection code in the project into the cleaner, more maintainable @WrapOperation / @WrapMethod style, with behavior fully equivalent to the original implementation.

Mixin Refactor Overview

- @Redirect -> @WrapOperation (12)
- @ModifyArg -> @WrapOperation (3)
- @Inject (HEAD cancel / RETURN return-value modification) -> @WrapMethod (14)
- @Inject (additional logic / complex injections) kept as-is (21)
